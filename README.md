# Comic Stars Fighting 3.6 - Web & Handheld Edition (RG557 Ready)

Trò chơi đối kháng crossover các nhân vật anime huyền thoại từ Shonen Jump:
* **One Piece:** Monkey D. Luffy, Roronoa Zoro, Portgas D. Ace, Sanji, Nami, God Enel.
* **Dragon Ball Z:** Son Goku (Siêu Saiyan), Vegeta, Gohan Siêu Saiyan, Majin Buu.
* **Naruto:** Naruto Uzumaki (Cửu Vĩ), Sasuke Uchiha, Sakura, Kakashi, Itachi, Gaara.
* **Bleach:** Ichigo Kurosaki (Bankai), Toshiro Hitsugaya, Renji Abarai, Byakuya Kuchiki.
* **Fairy Tail / Jump:** Natsu Dragneel, Erza Scarlet, Gon Freecss, Killua, Yugi Muto, Kenshin Himura...

## Tính năng:
- Chạy trực tiếp trên trình duyệt qua WebAssembly (Ruffle) không cần Flash Player.
- Tối ưu hóa điều khiển cho máy chơi game cầm tay **Anbernic RG557** (cần Analog, D-pad, nút vật lý A, B, X, Y, R1, L1 và rung Haptic Dual-Rumble).
- Cụm phím ảo cảm ứng linh hoạt cho thiết bị di động / màn hình cảm ứng.
- Tự động xóa cache khi có bản cập nhật mới (Auto Cache-Busting).
- Giao diện song ngữ **Tiếng Việt / English**.
- Nền đen thuần `#000000` tối ưu pin và hiển thị trên màn hình AMOLED.
